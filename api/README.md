# genetic-dna / api

🔜 **Planned.**

HTTP API that will:

- parse genotype files from consumer tests (starting with Genera's CSV format, GRCh37);
- annotate variants with public databases (ClinVar, PharmGKB/CPIC, GWAS Catalog, PGS Catalog);
- call the DNA language model from [`model/`](../model/) for zero-shot variant scoring.

Not for clinical use.
